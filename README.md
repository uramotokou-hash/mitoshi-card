# 見通しカード スケジュールメーカー

絵カードをえらんでならべ、見通しのスケジュール表（たて1列／よこならび／切り取りカード）や絵カードをA4で印刷・PDF保存できる無料Webアプリです。学校でも家庭でも使えます。

- アカウント登録なし・ブラウザだけで動きます
- 入力内容や写真はその端末の中だけに保存され、外部へは送信されません
